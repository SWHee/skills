# ADR-0001: 2주 기한을 우선한 기존 조회 방식 A 유지 제안

| 속성 | 값 |
| --- | --- |
| 날짜 | 2026-09-19 |
| 상태 | Proposed |

## Context and Problem Statement

사용자 제공 가상 문서 요약에 따르면 기존 A는 추가 요금이 없고 익숙한 REST 조회이며, 후보 B는 전용 스트림 endpoint·연결 관리와 월 고정 5단위가 필요합니다. 현재 서버는 한 대이며, 사용자는 2주 기한을 우선하고 약 10초 대기를 허용합니다. 활성 화면 30개는 예상이고 성능은 미측정이며, 최종 채택은 아직 하지 않았습니다.

## Decision Drivers

- 2주 기한을 우선하며 추가 구현·운영 부담을 줄입니다.
- 약 10초 대기 허용을 실제 환경에서도 만족하는지 확인해야 합니다.
- 현재 한 대 서버에 필요한 구성과 미래 분산 배포의 구성을 구별합니다.

## Considered Options

### A: 기존 REST 조회 유지

- 장점: 제공 요약상 추가 요금이 없고 익숙한 방식입니다. 이를 재사용하는 편이 일정 위험이 작다는 것은 추론입니다.
- 단점: 주기적인 요청과 지연이 남습니다. 30개 화면의 부하·지연은 미확인입니다.

### B: 전용 스트림 도입

- 장점: 반복 조회·대기를 줄일 가능성이 있습니다. 실제 감소 효과는 제공 자료에 없으므로 미확인입니다.
- 단점: 제공 요약상 월 고정 5단위와 endpoint·전용 연결 관리가 필요합니다. 2주 내 완료 가능성·성능은 미확인입니다.

## Decision Outcome

**현재 조건에서는 A 유지를 제안합니다. 최종 채택은 보류 상태입니다.**

익숙한 기존 구성을 활용할 수 있고 사용자가 일정과 약 10초 대기를 우선 조건으로 제시했습니다. B의 추가 구현·연결 관리와 요금에 비해 현재 반드시 얻어야 할 효과는 입증되지 않았습니다. 다만 A의 지연·부하 검증에서 문제가 확인되면 이 추천은 달라질 수 있습니다.

## Consequences

- 긍정적 영향: 새 스트림 구성 도입 부담을 피하고 기존 조회를 활용할 수 있습니다.
- 감수할 단점: 주기적 요청과 지연이 남습니다. 추가 요금 없음은 인프라·인건비까지 무료라는 뜻이 아닙니다.
- **필수 확인:** A의 주기적 요청 → 표시 지연과 처리 부담 → 요청 간격·처리 시간을 함께 측정합니다. 약 10초 대기를 만족해야 하는 현재 조건에 해당합니다.
- **B 선택 시 필수:** 전용 스트림 → 서버 endpoint·수신 연동 → 전용 연결 관리 설계가 필요합니다. 종료·재연결 대응의 구체 내용은 미확인이며 후속 설계 과제라는 추론입니다.
- **조건부:** 향후 여러 서버 분산 배포 → 서버 간 전달 → 제공 요약상 공유 전달 구성이 필요합니다. 현재 한 대 서버에서는 필수로 도입하지 않습니다.
- **선택적:** 전환 부담 감소 → 수신 방식과 화면 처리의 결합 → 둘의 분리를 검토할 수 있습니다. 현재 요구의 필수 조건은 아닙니다.
- 요금의 통화·적용 시점·포함 사용량·추가 전송 비용과 개발·운영 시간은 미확인입니다. 월 고정 5단위는 제공 요약의 값이며 총비용 계산을 수행하지 않았습니다.

## Confirmation

제공 자료만 비교했으며 웹·원문 문서·코드·실험은 확인하지 않았습니다. 자료의 최신성은 미확인입니다. 미실시 확인 계획은 서버 한 대에서 예상 활성 화면 30개를 재현하고 A의 변경 발생부터 표시까지 지연과 요청 부담을 측정하는 것입니다. 약 10초 대기 조건에 맞지 않으면 A의 간격 조정과 B 도입을 다시 비교합니다. 처리 시간도 포함하므로 10초 요청 간격만으로 지연 조건을 충족했다고 판정하지 않습니다.

## Reconsideration Conditions

- 허용 대기 시간이 현재 약 10초보다 짧아지면 A의 간격 조정 비용과 B 도입 효과를 재검토합니다.
- 예상 30개 활성 화면을 재현한 측정에서 지연 또는 운영상 처리 부담이 문제가 되면 A 조정과 B 도입을 비교합니다. 부하의 수치 기준은 아직 정해지지 않았습니다.
- 여러 서버로 분산 배포하게 되면 B의 공유 전달 구성과 그 운영 부담을 비교에 포함합니다.
- B의 실제 개발·운영 부담이나 지연 개선 근거가 확보되면 2주 기한과 월 고정 요금에 비추어 추천을 재평가합니다.
