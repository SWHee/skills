# 템플릿 출처와 조정

이 플러그인의 개인용 양식은 [MADR 4.0.0](https://github.com/adr/madr/blob/4.0.0/template/adr-template.md)의 구조를 참고한 한국어 작성 안내와 프로젝트별 조정이다. 공식 MADR 원문 그대로이거나 ADR 전체의 공인 표준이라고 주장하지 않는다.

MADR 프로젝트는 [MIT 또는 CC0-1.0](https://adr.github.io/madr/)을 제공한다. 이 템플릿에서 사용하는 MADR 부분은 CC0-1.0을 선택한다. 이는 플러그인 전체에 새 라이선스를 부여한다는 뜻이 아니다.

사용자가 제공한 부트캠프 동료의 `docs/ADR/adr-template.md`에서는 대안별 장단점과 독립된 `Reconsideration Conditions` 항목이라는 구조를 참고했다. 원본 파일은 수정하지 않았고 설명문은 새로 작성했다.

조정 사항:

- 제목 직후 날짜·상태를 읽을 수 있는 표 배치. 이 표는 본 플러그인의 표현 방식이며 MADR 원형의 필수 형식이 아니다.
- 작성자, 공유 대상, 결정권자 등 개인 기록에 불필요한 속성 제외.
- 후보별 장단점을 Considered Options에 모아 중복 비교 축소.
- Reconsideration Conditions를 별도 항목으로 유지.
- Confirmation과 References는 필요한 경우만 유지.
- 영문 항목명과 한국어 작성 안내 사용. 실제 ADR에서는 작성 안내 제거.
