- 조직에서 상속된 활성 ruleset이 있으나 기존 protected 플래그가 false인 경우와, 기존 branch protection만 있는 경우 모두 PR로 보내는 모의 테스트를 통과했다. 유효 규칙 조회의 일반 오류는 main 직접 쓰기를 막는다.

- 스킬 안내의 중복을 줄이고 macOS Codex 앱 사용 환경을 명시했다. CI 승격과 복구 기능은 원래 합의한 범위이므로 유지했다. 팀원이 변경한 항목의 자동 관리 해제는 보호 규칙 차이를 숨길 수 있어 채택하지 않았다.
- 이번 원격 검증은 읽기 요청만 사용했다. 신규 저장소·보드·초대는 만들지 않았다.
